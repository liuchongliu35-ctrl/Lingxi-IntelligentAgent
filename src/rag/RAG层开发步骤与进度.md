# RAG 层开发步骤与进度

本文档用于跨 Session 记录 RAG 层开发进度。

## 当前定位

RAG 层负责知识文档导入、切块、检索、上下文构建和带来源回答。当前仍是基础占位形态。

## 重点必看：跨 Session 进度更新规则

后续每完成一个可验收开发步骤，都必须同步更新对应层的进度文档。

```text
完成一个 Step
  -> 跑测试或完成逻辑验证
  -> 确认没有明显问题
  -> 更新对应层的“开发步骤与进度.md”
  -> 下一个对话继续未完成步骤
```

不需要每改一个小函数都更新；但完成一个清晰阶段后必须更新，并记录已完成内容、验证方式、当前未完成项和下一轮建议。
