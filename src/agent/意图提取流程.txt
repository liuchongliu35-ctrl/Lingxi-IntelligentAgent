文本清洗+分词 ✅️
    ↓
【1.2 多意图前置筛选】（基于分词结果判断显式连接词：并/然后/同时/以及等）
    ├─ ✅ 命中显式连接词 → 标记为多意图候选，进入【1.3 多意图提取】
    └─ ❌ 未命中显式连接词 → 进入【1.4 单意图提取流水线】


【1.3 多意图提取】
    ↓
【1.3.1 规则匹配器】（基于原文及分词，匹配意图词表，支持并列结构）
    ├─ ✅ 匹配到 ≥2 个意图 → 直接返回意图列表 → 进入【1.6 实体参数提取】
    ├─ ✅ 匹配到 1 个意图 → 暂存该意图，进入【1.3.2 轻量级多意图分类器】
    └─ ❌ 匹配到 0 个意图 → 进入【1.3.2 轻量级多意图分类器】
           ↓
【1.3.2 轻量级多意图分类器】（multi-label，输出每个意图的概率）
    ↓
    收集概率 > 阈值（如0.5）的意图 → 得到 cls_intents
    ├─ 若 cls_intents 为空或最大概率 < 阈值 → 进入【1.7 大模型兜底】
    ├─ 若 len(cls_intents) ≥ 2 → 返回 cls_intents → 进入【1.6 实体参数提取】
    └─ 若 len(cls_intents) == 1 → 暂存该意图，进入【1.3.3 不确定性判断】
           ↓
【1.3.3 不确定性判断】（计算分类器输出分布的熵或最大概率）
    ├─ ✅ 熵值 > 阈值（如0.7）或 最大概率 < 0.6 → 进入【1.7 大模型兜底】
    └─ ❌ 确定（唯一意图且较可信）→ 返回该单意图 → 进入【1.6 实体参数提取】
           （注：此时若原为多意图候选但实际为单意图，允许正常返回）





【1.4 单意图提取流水线】
    ↓
【1.4.1 规则匹配器】（基于分词，按优先级匹配意图词表）
    ├─ ✅ 命中 → 返回该意图 → 进入【1.6 实体参数提取】
    └─ ❌ 未命中 → 进入【1.4.2 轻量级单意图分类器】
           ↓
【1.4.2 轻量级单意图分类器】（多类分类，输出概率分布 p1≥p2≥...）
    ↓
【1.4.3 分类结果可靠性判断】
    ├─ 情况A：p1 > 0.85 → 高置信度 → 返回意图 i1 → 进入【1.6 实体参数提取】
    ├─ 情况B：0.6 < p1 ≤ 0.85 且 p1 - p2 > 0.2 → 中置信度且区分明显 → 返回 i1 → 进入【1.6 实体参数提取】
    ├─ 情况C：p1 ≤ 0.6 或 p1 - p2 ≤ 0.2 → 低置信度/模糊，疑似漏判多意图 → 进入【1.5 多意图复核】
    └─ 情况D：分类器输出“未知”类概率最高 → 返回 UNKNOWN → 进入【1.8 用户澄清】

【1.5 多意图复核】（对可疑的单意图重新检查是否为多意图）
    ↓
    以当前文本为输入，重新执行【1.3 多意图提取】的全部逻辑
    ├─ 若多意图提取返回 ≥2 个意图 → 接受该多意图结果 → 进入【1.6 实体参数提取】
    ├─ 若多意图提取返回 1 个意图（或空） → 仍无法确定 → 进入【1.7 大模型兜底】
    └─ 若多意图提取返回 UNKNOWN → 进入【1.7 大模型兜底】

【1.6 实体参数提取】（常规流程，略）

【1.7 大模型兜底】（严格边界）
    ↓
    构造大模型输入（原文 + 上下文 + 已知意图列表 + 输出格式约束）
    要求：只能从已知意图中选择，允许输出 unknown，支持多意图（最多3个）
    ↓
    解析大模型输出
    ├─ 若输出 unknown 或解析失败 → 返回 UNKNOWN → 进入【1.8 用户澄清】
    └─ 若输出有效意图列表（非空） → 返回该列表 → 进入【1.6 实体参数提取】

【1.8 用户澄清】
    ↓
    通知用户意图不明确，引导重新输入或补充信息
