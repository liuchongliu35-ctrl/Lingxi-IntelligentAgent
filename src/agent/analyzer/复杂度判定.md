一、核心判定策略
定量模型+定性规则的混合策略：以七维度加权评分模型为基础进行全面定量分析，辅以启发式规则对极端情况进行快速定性判断和"短路"处理，兼顾判断的全面性与高效性。
二、第一层：定量基础——七维度加权评分模型
当任务未触发启发式规则时，进入此模型计算基础复杂度分。
维度	权重	核心考量
不确定性与模糊度	3.0（最高）	指令是否清晰明确，有无歧义或开放性问题
步骤数量与依赖性	2.0	完成任务所需步骤数量，以及步骤间的依赖关系（线性流程vs复杂依赖网络）
领域专业性与风险	1.8	是否涉及法律、金融、医疗等特定专业领域，以及潜在风险
工具需求与组合	1.5	需要调用的工具数量，以及工具间的协同和数据传递方式
信息获取与来源	1.5	是否需要从外部获取信息，以及信息源的多少和可靠性
数据处理与分析	1.2	是否涉及结构化或非结构化数据的处理、分析和转换
创造性与生成需求	1.0	是否需要生成新内容、设计或提供个性化建议
分数区间映射：
● 0-10分：简单任务
● 11-30分：中等任务
● 31分以上：复杂任务
三、第二层：定性捷径——启发式规则（优先级高于定量模型）
用于快速处理极端情况，避免不必要的计算和资源浪费。
规则1：模糊性优先
● 触发条件：指令充满不确定性（如"帮我分析一下市场"），存在大量未知项
● 判定结果：直接判定为"模糊任务"
● 执行策略：启动Macro（宏观层）对话模式，主动向用户澄清具体需求
规则2：高风险优先
● 触发条件：涉及法律、金融、医疗等高风险领域（如"帮我起草一份房屋租赁合同"）
● 判定结果：自动将任务复杂度提升一个等级
● 执行策略：启用"谨慎模式"，执行前后主动发出风险提示，生成内容标注需专业审核的关键条款
规则3：简单任务捷径
● 触发条件：目标明确、步骤单一、工具固定（如"计算1024×768"）
● 判定结果：直接判定为"极简单任务"
● 执行策略：启动Micro（微观层）策略，直接调用工具执行，无需规划
四、基于复杂度的三层执行策略
策略层次	适用场景	执行方式	典型案例
Micro（微观层）	简单任务（0-10分）、极简单任务	直接执行，无需规划	计算数值、复制文件
Meso（中观层）	中等任务（11-30分）	创建结构化多阶段计划，分步执行	搜索并总结5篇论文
Meso高级	复杂任务（31分以上）	创建详细多阶段计划，包含多个开发/执行阶段	开发一个博客网站
Macro（宏观层）	模糊任务	先对话澄清需求，再重新评估	帮我分析一下市场
五、完整决策流程
1. 接收用户指令
2. 快速检查三条启发式规则（模糊性→高风险→极简单）
3. 若命中任意一条，立即执行相应策略
4. 若均未命中，进入七维度加权评分模型计算总分
5. 根据分数区间映射到对应的复杂度等级和执行策略
6. 执行过程中动态调整：若发现实际复杂度与初步判断不符，重新评估并调整策略

步骤2：启发式规则快速判断（优先级从高到低）
目标：用最少的计算资源处理80%的极端情况，避免进入复杂的评分流程
判断顺序：模糊性规则 → 高风险规则 → 简单任务规则
规则1：模糊性优先规则（最高优先级）
触发条件（满足任意一条）：
● 指令中包含"分析一下"、"看看"、"帮我弄一下"等模糊动词
● 缺少核心参数（如"帮我分析市场"缺少"哪个市场"、"分析什么"）
● 存在歧义性表述（如"帮我写个东西"）
● 指令长度小于5个字符且无明确意图
具体实现：
1. 维护一个模糊关键词库：["分析", "看看", "弄一下", "搞一下", "做点", "随便"]
2. 检查结构化任务对象中的parameters是否包含所有必要参数（根据意图类型定义）
3. 若触发，直接返回"complexity_level": "ambiguous"
4. 执行策略：启动Macro澄清对话，生成3-5个针对性问题
您指的是哪个具体市场？(股票市场、房地产市场、消费品市场…)
您希望分析市场的哪些方面？(规模、趋势、竞争格局…)
分析的目的是什么？(投资决策、学术研究、商业计划…)
规则2：高风险优先规则
触发条件（满足任意一条）：
● 涉及法律领域：合同、协议、律师函、诉讼、遗嘱等
● 涉及医疗领域：诊断、治疗、处方、用药建议等
● 涉及金融领域：投资建议、股票分析、贷款、保险等
● 涉及隐私安全：个人信息、密码、身份证号等
具体实现：
1. 维护一个高风险关键词库和意图库
2. 若触发，在后续评分基础上自动加10分（复杂度提升一个等级）
3. 执行策略：启用"谨慎模式"
  ○ 执行前：强制显示风险提示
  ○ 执行中：优先使用权威数据源
  ○ 交付时：再次提醒用户寻求专业意见
规则3：简单任务捷径规则
触发条件（同时满足所有）：
● 意图明确且单一（如计算、复制、删除、查询天气）
● 所有必要参数齐全
● 只需调用一个工具即可完成
● 步骤数≤1
具体实现：
1. 维护一个简单任务意图库：["calculate", "copy", "delete", "weather", "time"]
2. 检查工具调用数量是否为1
3. 若触发，直接返回"complexity_level": "simple"
4. 执行策略：直接调度Micro执行器，跳过规划阶段
步骤3：七维度加权评分计算
目标：对未触发启发式规则的常规任务进行全面定量评估
具体操作：
1. 对每个维度进行0-5分的评分（0=无，5=极高）
2. 乘以对应权重得到加权分
3. 累加所有加权分得到总分
各维度评分标准（可量化）：
维度	权重	0分	2分	4分	5分
不确定性与模糊度	3.0	指令完全清晰，无歧义	有轻微模糊性，但核心目标明确	有较大模糊性，需要少量澄清	完全模糊，无法理解意图
步骤数量与依赖性	2.0	1步，无依赖	3-5步，线性依赖	6-10步，部分并行依赖	10步以上，复杂依赖网络
领域专业性与风险	1.8	通用领域，无风险	一般专业领域，低风险	高专业领域，中风险	极高专业领域，高风险
工具需求与组合	1.5	无需工具	1-2个工具，简单组合	3-4个工具，需要数据传递	5个以上工具，复杂协同
信息获取与来源	1.5	无需外部信息	1个信息源	2-3个信息源	4个以上信息源
数据处理与分析	1.2	无需数据处理	简单文本处理	结构化数据处理	复杂数据分析与建模
创造性与生成需求	1.0	无需生成内容	简单改写与填充	原创内容生成	复杂创意设计
计算示例：
任务：搜索关于大语言模型最新进展的5篇论文并总结核心贡献
不确定性与模糊度：1分 × 3.0 = 3.0
步骤数量与依赖性：3分 × 2.0 = 6.0
领域专业性与风险：2分 × 1.8 = 3.6
工具需求与组合：3分 × 1.5 = 4.5
信息获取与来源：3分 × 1.5 = 4.5
数据处理与分析：2分 × 1.2 = 2.4
创造性与生成需求：2分 × 1.0 = 2.0
总分：3.0+6.0+3.6+4.5+4.5+2.4+2.0 = 26.0分
步骤4：复杂度等级映射
目标：将定量评分转换为系统可识别的复杂度等级
映射规则：
● 0-10分：简单任务 → Micro执行器
● 11-30分：中等任务 → Meso执行器（基础版）
● 31分以上：复杂任务 → Meso执行器（高级版）
注意：高风险任务加10分后再进行映射
● 例如：原评分25分（中等），触发高风险规则后变为35分（复杂）
步骤5：执行策略初始化与调度
目标：根据复杂度等级启动对应的执行器
各执行器具体操作：
Micro执行器（简单任务）
1. 直接调用对应的工具
2. 获取工具返回结果
3. 格式化后返回给用户
4. 任务结束
Meso执行器（基础版，中等任务）
1. 生成结构化多阶段计划（3-5个阶段）
2. 按顺序执行每个阶段
3. 每个阶段完成后检查结果
4. 所有阶段完成后整合结果
5. 返回给用户
Meso执行器（高级版，复杂任务）
1. 生成详细的多阶段计划（5个以上阶段）
2. 分解为子任务，分配给不同的子Agent
3. 协调子任务的执行顺序和数据传递
4. 定期检查进度，处理异常情况
5. 整合所有子任务结果
6. 生成最终报告返回给用户
步骤6：执行中动态监控与重评估
目标：处理执行过程中发现的实际复杂度与初步判断不符的情况
触发重评估的条件：
● 某个阶段执行失败超过3次
● 发现需要额外调用未计划的工具
● 发现需要获取更多的外部信息
● 用户在执行过程中修改了指令
重评估流程：
1. 暂停当前执行
2. 重新计算七维度评分
3. 更新复杂度等级
4. 调整执行计划
5. 继续执行
